TableGrab 表格抓取 · 设置

网页表格批量导出插件的运行参数。所有设置保存在浏览器本地，修改后立即生效。

🎉 安装成功！打开任意网页，点击右下角「提取表格」悬浮按钮即可扫描表格。

悬浮按钮

控制网页右下角「提取表格」按钮的显示。按钮支持拖拽移动，位置会被记住。

表格过滤规则

用来过滤空表格与布局装饰表格。数值调小会保留更多表格，调大会只保留结构完整的数据表。

导出偏好

仅影响导出文件名，正文数据不受影响。默认文件名规则：page_table_日期_序号.扩展名，例如 page_table_20261015_001.csv。

功能自检

使用当前过滤规则，对最近浏览过的普通网页执行一次试扫，用来确认规则是否过严。

使用说明

  1. 打开任意含表格的网页，点击右下角 「提取表格」 悬浮按钮（可用鼠标拖拽调整位置）。
  2. 插件会自动打开新标签页列出本页全部表格，支持搜索、勾选、预览、查看原始 HTML。
  3. 选择导出格式（CSV / Excel 兼容 CSV / Markdown / JSON）与导出方式，点击「导出选中」。
  4. 文件会保存到浏览器默认下载目录，文件名形如 page_table_20261015_001.csv。

小提示：SPA（Vue / React 单页应用）页面内容变化后，可直接在预览页点击「重新提取」重新扫描； 也可以在网页上按 Alt+Shift+T，或点击浏览器工具栏中的插件图标。
