核心功能

从「看到表格」到「拿到文件」，只需要三步

不用再手工复制粘贴，也不用为不同格式反复调整。插件把识别、预览、勾选、导出串成一条流程。

一键扫描全页表格

页面右下角常驻「提取表格」悬浮按钮，点击即扫描全部原生 <table>， 自动识别 thead / tbody / td / th 结构，并展开合并单元格。

智能过滤无效表格

自动剔除行列过少的空表、用表格做页面排版的装饰表格；最小行列阈值可在设置页自由调整， 过滤规则随时可关。

新标签页预览勾选

独立预览页列出全部表格，卡片式展示行列统计与迷你预览表格，支持关键字搜索、 全选 / 反选 / 清除已选，大表格可横向滚动。

四种格式批量导出

CSV、Excel 兼容 CSV（带 BOM 与 CRLF）、Markdown 表格、JSON。 可每张表格单独一个文件，也可合并成一个文件，文件名形如 page_table_20261015_001.csv。

兼容 SPA 动态网页

Vue / React / Angular 单页应用里异步渲染出来的表格同样能抓到：每次点击都是实时扫描， 内容更新后在预览页点「重新提取」即可刷新数据。

数据本地处理

表格数据只在浏览器内存与本地存储中流转，通过 chrome.downloads 保存到默认下载目录，不发送到任何第三方服务器。

使用流程

三步拿到干净的结构化数据

按钮支持拖拽到不遮挡内容的位置，位置会被记住，下次打开网页依然在原处。

1

点击「提取表格」

悬浮按钮位于页面右下角，也可以按 Alt+Shift+T 或点击浏览器工具栏中的插件图标触发。

2

在预览页勾选表格

新标签页会列出本页所有有效表格，默认全选。可按标题或内容搜索，逐张确认预览后取消不需要的表格。

3

选择格式导出

选择导出格式与导出方式，点击「导出选中」，文件会直接进入浏览器的默认下载目录。

导出示例

同一张表格，四种可直接使用的格式

下面以网页上的「销售报表」表格为例，展示四种导出格式的真实内容。

城市,销售额,同比
北京,"1,240,000",+12%
上海,980,000,-3%
广州,"1,015,000",0%

标准 CSV：含逗号的单元格自动加双引号包裹，双引号转义成两个双引号，换行与回车同样会被正确处理。

（文件以 UTF-8 BOM 开头，换行使用 CRLF）

城市,销售额,同比
北京,"1,240,000",+12%
上海,980,000,-3%
广州,"1,015,000",0%

Excel 兼容 CSV：写入 BOM 头并改用 CRLF 换行，双击即可用 Excel 正确打开、中文不乱码。

| 城市 | 销售额 | 同比 |
| --- | --- | --- |
| 北京 | 1,240,000 | +12% |
| 上海 | 980,000 | -3% |
| 广州 | 1,015,000 | 0% |

Markdown 表格：单元格里的竖线会自动转义、换行转成 <br>，可直接粘贴进文档或笔记系统。

{
  "index": 1,
  "title": "2026 年一季度销售报表",
  "rowCount": 3,
  "colCount": 3,
  "headers": ["城市", "销售额", "同比"],
  "records": [
    { "城市": "北京", "销售额": "1,240,000", "同比": "+12%" },
    { "城市": "上海", "销售额": "980,000", "同比": "-3%" }
  ],
  "matrix": [["城市","销售额","同比"], ["北京","1,240,000","+12%"]]
}

JSON：同时给出 headers / records 结构化数据和原始 matrix 二维数组， 方便直接对接接口或脚本处理。

批量导出时会按勾选顺序编号： page_table_20261015_001.csv、 page_table_20261015_002.csv…… 选择「合并为一个文件」时则输出 page_table_20261015_all.csv。

Edge 离线安装

三步加载到 Microsoft Edge

扩展以「加载解压缩的扩展」方式离线安装，无需上架应用商店，也不需要开发者账号。

  1. 1

    打开扩展管理页面

    在 Edge 地址栏输入下面的地址并回车：
    edge://extensions/
  2. 2

    开启「开发人员模式」

    打开页面左下角的开发人员模式开关，顶部工具栏会多出「加载解压缩的扩展」按钮。
    Edge 与 Chrome 内核一致，插件在 Chrome 的 chrome://extensions/ 中同样可以加载使用。
  3. 3

    选择插件目录完成加载

    点击加载解压缩的扩展，选中包含 manifest.json 的项目文件夹即可。 加载成功后工具栏会出现蓝色表格图标，打开任意含表格的网页就能看到右下角的「提取表格」按钮。
    提示：首次导出多个文件时，Edge 可能询问「是否允许下载多个文件」，选择允许即可。

常见问题

你可能关心的几个问题

插件默认会过滤「行列过少」「几乎全空」「用表格做排版」的装饰性表格。可以在插件设置页把 最小有效行数 / 列数 调小，或关闭「过滤布局装饰表格」后重新提取。
选择导出格式里的 Excel 兼容 CSV。该格式会写入 UTF-8 BOM 头并使用 CRLF 换行， Excel 能自动识别编码，不会出现乱码。
不会。表格解析、格式转换全部在浏览器本地完成，文件通过浏览器下载接口直接保存到本地下载目录， 扩展没有任何服务端接口。
每次点击「提取表格」都会实时重新扫描当前 DOM，所以在 SPA 里切换到对应标签页后直接点按钮即可。 如果表格是异步加载的，稍等数据出现后再点击，或在预览页使用「重新提取」。
