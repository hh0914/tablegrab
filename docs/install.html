Edge 离线安装与使用教程

TableGrab 以「加载解压缩的扩展」方式安装，不需要应用商店账号，也不需要联网下载。 整个过程大约 30 秒。

开始之前

确认你拿到的是完整的插件文件夹，其中必须包含 manifest.json 文件。 目录内至少应该有下面这些内容：

manifest.json     ← 关键文件，Edge 通过它识别扩展
background.js
content.js
content.css
table-gallery.html / .js / .css
options.html / .js / .css
lib/  icons/
注意：要选择的是包含 manifest.json 的那一级文件夹。 如果选错层级，Edge 会提示「无法加载扩展程序，清单文件缺失或不可读」。

安装步骤

  1. 1

    打开扩展管理页面

    打开 Microsoft Edge，在地址栏输入下面的地址并回车（也可以点击右上角「…」→「扩展」→「管理扩展」）：
    edge://extensions/
    使用 Google Chrome 的话，地址是 chrome://extensions/，其余步骤完全一致。
  2. 2

    开启「开发人员模式」

    在扩展页面左下角找到开发人员模式开关并打开。打开后页面顶部会出现 「加载解压缩的扩展」「打包扩展」等按钮。
  3. 3

    点击「加载解压缩的扩展」并选择插件文件夹

    在弹出的文件夹选择窗口中，定位到插件目录，选中包含 manifest.json 的那一层，确认即可。
    • 加载成功后，扩展列表里会出现 TableGrab 表格抓取 卡片。
    • 浏览器工具栏会出现蓝色的表格图标；点击工具栏的「扩展」图标可以把它固定到显眼位置。
    • 首次安装会自动打开设置页，介绍基本用法。
  4. 4

    验证安装结果

    打开任意含表格的网页（例如任意一个数据报表页面），页面右下角应出现蓝色的 「提取表格」 悬浮按钮。
    • 如果按钮没出现，先按 F5 刷新一次页面（内容脚本只对刷新后的页面生效）。
    • 点击浏览器工具栏的插件图标，或按 Alt+Shift+T 也能触发扫描。
使用说明

一次完整的导出流程

以「导出网页上 3 张表格为 Excel 兼容 CSV」为例。

① 提取表格

点击右下角悬浮按钮。按钮支持按住拖动，位置会被记住；扫描过程中图标会旋转，完成后提示「已提取 N 张表格」。 如果本页没有符合条件的表格，会直接提示共发现多少个 <table>、过滤掉多少个。

② 在预览页确定要导出的表格

  • 预览页默认全选所有表格，不需要的表格取消勾选即可。
  • 用顶部搜索框输入关键字（标题、内容、行列数都支持）快速定位。
  • 用「全选 / 反选 / 清除已选」批量调整；右上角计数器实时显示「已选 N / M」。
  • 点击卡片上的「展开全部行」查看完整数据，「查看源码」可以看到该表格的原始 HTML 片段。

③ 选择导出格式与导出方式

选项 说明
导出格式 CSV / Excel 兼容 CSV（含 BOM） / Markdown 表格 / JSON
导出方式 每个表格单独文件（_001、_002…）或全部合并为一个 _all 文件
文件名带网页标题前缀 勾选后文件名前面会加上来源网页标题，便于多页面导出后区分

这三项选择会被记住，下次打开预览页时自动沿用。

④ 点击「导出选中」并收取文件

  • 底部状态栏会显示「已导出 2 / 3」这样的实时进度。
  • 文件保存到浏览器的默认下载目录，点击状态栏右侧「打开下载目录」可以直接跳转。
  • 同名文件不会覆盖，浏览器会自动追加序号。
  • 如果 Edge 弹出「是否允许下载多个文件」的询问，选择允许即可。

⑤ 常用快捷键与入口

入口 说明
右下角悬浮按钮 最常用，可在设置页关闭
工具栏插件图标 等效于点击悬浮按钮，适用于按钮被网页遮挡的情况
Alt+Shift+T 键盘快捷键，可在 edge://extensions/shortcuts 中自定义
预览页「重新提取」 重新扫描来源网页并在当前预览页刷新数据，适合 SPA 页面内容更新后使用

更新、卸载与常见安装问题

修改代码后如何让扩展生效

  1. 在 edge://extensions/ 找到 TableGrab 卡片，点击刷新按钮（圆形箭头图标）。
  2. 回到目标网页按 F5 刷新，让新的内容脚本重新注入。
  3. 如果修改的是 manifest.json 的权限或内容脚本配置，建议先点「移除」再重新「加载解压缩的扩展」。

卸载

在 edge://extensions/ 的 TableGrab 卡片上点击「删除」，或在卡片右下角点击「移除」， 同时勾选清除本地数据即可删除悬浮按钮位置、过滤阈值等设置。

安装时可能遇到的提示

提示信息 原因与解决办法
清单文件缺失或不可读 选择的目录层级不对，请选中直接包含 manifest.json 的那一层文件夹
清单文件不是有效的 JSON manifest.json 被编辑器写入了 BOM 或注释，请保存为无 BOM 的 UTF-8 纯 JSON
无法从该网站添加应用 本地文件夹不受此限制，请使用「加载解压缩的扩展」而不是拖拽到扩展商店页面
扩展图标是灰色的 当前页面是浏览器内置页面（edge://、扩展商店等），浏览器禁止注入，切换到普通网页即可
更多交互细节见 功能详解，其他问题见 常见问题。

安装完成，去抓一张表试试

打开任意数据报表页，点击右下角「提取表格」，几十秒后你就能拿到一份干净的表格文件。
