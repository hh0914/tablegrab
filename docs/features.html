功能详解

从表格识别、过滤规则、合并单元格处理，到四种导出格式与批量导出方式，这里是 TableGrab 的完整能力说明。

1. 表格识别与解析

点击悬浮按钮后，插件会对当前页面执行一次实时扫描，收集所有 <table> 元素并逐张解析：

  • 结构识别：遍历 table.rows 得到全部 <tr>，再遍历每行的 <td> / <th>，<thead>、 <tbody>、<tfoot> 中的行都会按文档顺序纳入。
  • 合并单元格展开：rowspan / colspan 会被还原成规整的二维数组， 被占用的格子补空字符串，保证每行长度一致，导出后不会出现错列。
  • 文本提取：优先使用 innerText（能正确反映 <br> 与 CSS 隐藏内容）， 超大表格改用 DOM 遍历以节省性能，两种方式都会保留单元格内的换行。
  • 无文字单元格兜底：只有图标或输入框的单元格会读取图片 alt 或 input.value， 避免导出出现整列空白。
  • 表格标题推断：依次尝试 <caption>、aria-label、 data-title、title 属性，再向上查找最近的 <h1>~<h6> 标题， 最后退化为首个表头行。
  • 多行表头合并：<thead> 含多行时会把它们合并成一行复合表头， 例如「2026 / Q1」会合并为「2026 - Q1」，让 JSON 的字段名更有意义。

2. 无效表格过滤规则

网页里大量 <table> 只用于页面排版，插件默认会剔除下列情况，规则均可调整：

过滤规则 判定条件 默认值
行列过少 行数或列数小于设定阈值 最小 2 行 / 2 列
内容为空 整张表有效单元格少于 2 个，或文本总长度为 0 始终启用
布局装饰表 行数 ≤ 2 且 80% 以上单元格直接放置块级容器，同时文字极少 启用（可关闭）
嵌套布局表 表内直接嵌套表格且自身几乎没有文字 启用（可关闭）
隐藏表格 display:none、visibility:hidden 或没有任何几何矩形 保留，仅标记「页面中隐藏」
被过滤的表格不会被丢弃统计：预览页顶部会提示本次过滤了多少张表格， 设置页的「功能自检」还能对最近浏览的网页做一次只统计不导出的试扫，帮助你判断阈值是否过严。

3. 四种导出格式

格式 文件扩展名 适用场景 特殊处理
CSV .csv 通用数据交换、脚本处理 含逗号 / 引号 / 换行的字段自动加引号包裹并转义
Excel 兼容 CSV .csv 直接用 Excel 打开、给同事查看 追加 UTF-8 BOM 头，换行改为 CRLF，中文不乱码
Markdown 表格 .md 写进文档、笔记、Issue 描述 竖线转义为 \|，换行转成 <br>，列宽自动补齐
JSON .json 对接接口、程序读取 同时输出结构化 records 与原始 matrix，重名表头自动去重

导出时会用当前勾选的顺序编号：单独文件模式生成 page_table_20261015_001.csv、page_table_20261015_002.csv……； 合并模式生成 page_table_20261015_all.csv，多张表格之间以分节标题分隔，Excel 中依然可读。

勾选设置页的「文件名带网页标题前缀」后，文件名会变成 2026年一季度销售报表_page_table_20261015_001.csv，方便多页面导出后区分来源。

4. 预览页交互

  • 默认全选所有表格，取消勾选只需点一下复选框；「仅导出此表」可以一键只导出当前这张。
  • 顶部搜索框支持按标题、行列数、单元格内容关键字过滤，多个关键字用空格分隔表示「同时满足」。
  • 每张卡片都有「展开全部行」「查看源码」「复制」按钮；复制的内容是 TSV 格式，可直接粘贴进 Excel。
  • 表格卡片显示行列数、是否识别到表头、是否被截断、是否在页面中隐藏，以及可直接在控制台使用的定位选择器。
  • 卡片数量超过 40 张时分批渲染，避免长列表卡顿；底部状态栏实时显示导出进度。

5. SPA 动态网页兼容

插件不会缓存页面的初始快照，每次点击「提取表格」都是对当前 DOM 的实时扫描，因此：

  • Vue / React / Angular 渲染出的表格，只要已经出现在 DOM 中就能被抓到。
  • 页面内容更新后，在预览页点击「重新提取」会重新扫描来源网页并刷新同一个预览标签页，不会不断开新标签。
  • 部分框架会整块替换 <body>，插件通过 MutationObserver 监听并自动重新挂载悬浮按钮。
  • 悬浮按钮挂在 <html> 下的独立 Shadow DOM 中，不会参与框架的虚拟 DOM diff，也不会影响页面原有样式。

6. 权限说明与项目结构

扩展只申请完成功能所必需的权限，含义如下：

权限 用途
activeTab / scripting 在扩展刚安装、页面尚未刷新时，向当前标签页补注入内容脚本
downloads 把导出的文件保存到浏览器默认下载目录，以及打开下载目录
storage 保存悬浮按钮开关、按钮位置、过滤阈值与导出偏好
host_permissions: <all_urls> 在任意网页注入悬浮按钮并读取页面表格结构

项目目录结构

tablegrab/
├── manifest.json          # Manifest V3 清单：权限、内容脚本、后台脚本
├── background.js          # Service Worker：消息路由、数据暂存、生成并下载文件
├── content.js             # 内容脚本：悬浮按钮注入 + 页面表格解析
├── content.css            # 悬浮按钮样式（注入 Shadow DOM）
├── table-gallery.html     # 预览页：表格列表、勾选、导出交互
├── table-gallery.js
├── table-gallery.css
├── options.html           # 设置页：悬浮按钮开关、过滤阈值、导出偏好
├── options.js
├── options.css
├── lib/
│   └── table-utils.js     # 公共纯逻辑：网格重建、CSV/Markdown/JSON 格式化、文件名
├── icons/                 # 16 / 32 / 48 / 128 图标
├── docs/                  # 本静态官网（与扩展运行无关，可单独部署）
└── dev/                   # 开发工具：图标生成脚本、自动化测试、手工测试页
技术栈：原生 JavaScript（无框架、无打包工具），Manifest V3， 内容脚本 + Shadow DOM 隔离，Service Worker 负责下载与格式化；docs/ 为纯静态宣传页。
